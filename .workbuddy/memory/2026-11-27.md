## 经验
- 公开仓库 contents API 不带令牌可读（HTTP 200，CORS `*`）；页面里 fetch 需注意 Authorization 头带假令牌会被 401，公开读取不要带令牌。
- Gemini/Claude 等国外 AI 未加入跳转（国内访问不稳），只放 6 个国内主流。
- WorkBuddy 右侧预览面板的 localStorage 按本地 HTTP 服务 origin 隔离，重新打开页面地址可能变、令牌会丢；独立 Edge 打开 D 盘文件更稳。
- raw.githubusercontent.com 超时时，GitHub API contents 接口是可靠替代（同域名、带令牌、返回 base64 需解码）。
