## 修 bug：拉回数据失败
- 现象：用户点同步后提示"课表已抓取，但拉回数据失败"——令牌、触发、抓取都成功，只卡在最后拉回。
- 原因：`raw.githubusercontent.com` 在当前网络超时（curl 直接请求也返回 HTTP 000）；GitHub API contents 接口同域名返回正常。
- 修复：新增 `fetchViaApi()` 走 `/contents/code/personal-dashboard/courses.json`，base64 解码；拉回时优先 API、失败回退 raw。
- 验证：无头 Edge + 真实令牌实测拉回 18 条最新课表（19:49:06，正方教务系统）；用户右侧面板重试成功。
